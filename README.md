# Primeiro Passo v0.5.5 — trilhas com assuntos próprios

Corrigidos os destinos repetidos da jornada, mantendo cores, cartões e navegação.

- Descoberta: interesses, competências e comparação de caminhos profissionais.
- Capacitação: lacunas de competências e cursos recomendados.
- Currículo inteligente: organização do currículo e experiências.
- Busca e seleção: rotina de busca, acompanhamento de candidaturas e preparação para entrevistas.
- Entrada e adaptação: primeiro dia, primeira semana e plano dos primeiros 30 dias.
- Desenvolvimento: feedback, prática profissional e plano de 90 dias.
- Ser Humano no Trabalho: permanece como conteúdo especial independente.

Os atalhos da página inicial e da aba Trilhas usam os mesmos destinos. As quatro novas telas incluem leitura orientada, atividades e anotações salvas separadamente. Use Salvar esta etapa antes de sair. As marcações registram atividades realizadas; não alteram automaticamente os indicadores antigos de contratação, cursos ou candidaturas.

## Atualizar no VS Code
Faça backup do projeto atual. Substitua lib, pubspec.yaml e pubspec.lock pelos deste ZIP. Copie test para executar os testes. Preserve as pastas de plataforma e suas configurações. Encerre o app, execute flutter pub get e depois flutter run -d chrome.

Os dados anteriores do perfil continuam compatíveis. A integração de vagas da v0.5.4 foi preservada; consulte INTEGRACAO_VAGAS.md. Nenhuma empresa está conectada automaticamente. Este ZIP contém código-fonte, não um APK.
